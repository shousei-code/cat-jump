# 海ちゃんの放課後♡ゲーマー日記

小学6年生の天才ゲーマー「海（うみ）」を主人公にした、全7日間の一人用ブラウザゲーム。

## 遊べる内容
- 制服の学校生活。男の子3人・女の子3人のクラスメイトとの選択式会話、なかよし度と応援。
- 帰宅してゲーム練習（1日2種目まで）、猫と犬のパオパオとのふれあい。
- 記憶・リズム・スターキャッチの3種目。マウス・タッチ対応。リズムはSpaceでも操作。
- 7日目の大会は3種目のベスト記録を採用。再挑戦自由。総合点に応じて金・銀・友情の3エンディング。
- 練習をしない日や低い得点でも必ず物語を最後まで進められる。
- 自動保存、再開、大会再挑戦、新しい週の開始（最高記録保持）。

恋愛・告白の意味が未確定だったため、今回の物語は同級生との友情・憧れ・応援として実装。オンライン通信、外部課金、広告、個人情報収集はない。「きらめき」は頑張った記録で、購入用通貨ではない。

## 起動
リポジトリのルートで `python -m http.server 8000` を実行し、`http://localhost:8000/umi/` を開く。ビルドと外部パッケージ不要。GitHub Pages main/rootで配信可能。

## 保存
`localStorage` の `umi-gamer-v1`。会話選択・練習結果・大会ベストを保存。ミニゲームの途中状態は保存せず、画面を離れたら中断してやり直せる。元のデータが壊れている場合は上書きを停止。他ゲームの保存キーを変更しない。端末間の同期はない。

## 得点
大会は3種目平均×0.85 + 練習能力の合計÷12（上限10）+ なかよし度の合計÷5（上限5）。80点以上で金、55点以上で銀、それ未満は友情エンディング。
リズムは12拍、許容±0.45秒。連打しても同じ拍は1回だけ採点。スターキャッチは12秒以内に12個、記憶は正答率を採用。

## 素材
`assets/home.png` と `assets/school.png` はユーザーの参考キャラクターをもとに画像生成した新規イラスト。背景とキャラクターが一体の絵で、着せ替え・Live2Dは実装していない。

## テスト
```
node --test umi/tests/core.test.mjs
python umi/tests/browser.py
```
ブラウザ検証にはPython PlaywrightとChromiumが必要。コアは日次制限・7日間進行・3エンディング・保存・得点処理を確認。ブラウザは1280px/393pxで初日から大会・エンディング・再読み込みまで実際の操作で検証する。
実機iPhone/Safariと公開後URLの到達確認は未実施。
