# こむぎのジャンプ日和

茶トラの子猫と遊ぶ、依存パッケージ不要のブラウザーゲーム。

## 起動

このディレクトリで `python3 -m http.server 8001 --bind 127.0.0.1` を実行。
`index.html` をブラウザーで開く。スペース・上矢印キー・画面タップでジャンプ。Esc またはボタンで一時停止。

## GitHub Pages

このフォルダーの内容（index.html、game.js、assets）をゲーム専用リポジトリの main ブランチに保存。
GitHub の Settings → Pages → Deploy from a branch → main / (root) → Save。
表示される公開 URL から遊べます。パソコン・タブレット・スマホ向けのレスポンシブ表示とタップ操作に対応。
公開・リポジトリ作成はまだ実施していません。

制作の続きを別端末で行う際は、変更をコミットして GitHub に push してから、同じリポジトリを開いてください。
ベストスコアはブラウザーの localStorage にのみ保存。端末間同期はありません。

猫の画像はこのゲーム用に AI 生成。外部 CDN・認証・バックエンドは使いません。

## 3D: こもれびタウン

`dollhouse/` を開くと遊べる3Dのお部屋と街。Three.js 0.180.0 を同梱（MIT、vendor/THREE-LICENSE.txt）。外部CDNは不要。

- 床をタップ、または矢印キーで移動。街の建物・住民をタップ、または行き先ボタンで移動。
- 家具を選んで移動・回転・追加。選択後の「削除」、または「置いてある家具」の一覧から削除可能。Deleteキーも対応。
- 顔のテクスチャ、長い髪、リボンとレースの服を持つオリジナルの人形風キャラクター。髪・服・壁紙の色を変更可能。
- パン屋・ごはん屋：3人の注文を正しく渡すお仕事で45/60コイン。買った食べ物をバッグから食べると元気が回復。
- 住民3人：会話やプレゼントで仲良くなり、お散歩に誘える。
- 猫またはうさぎを1匹迎え、名前をつけ、ごはんをあげられる。ペットは家でも街でも追いかけてくる。
- 家具・色の従来セーブを維持。お金・持ち物・友好度・ペットは別のlocalStorageキーに保存。お部屋のリセットは街の進行に影響しない。
- 保存は現在のブラウザーのみ。端末間同期、他のプレイヤーとの通信、自由な建築、本格的な経路探索は未実装。
- WebGL対応ブラウザーが必要。実機のSafari/iPadでは未検証。

### 検証

`node --test tests/life-state.test.mjs` で売買・給料・食事・プレゼント・ペット・セーブ検証。
ブラウザーの検証にはPython PlaywrightとChromiumを使用。ローカルサーバーを8001番ポートで起動して `python3 tests/browser-smoke.py` を実行。スマホ操作だけの再検証は `python3 tests/mobile-smoke.py`。

## ウサギのアスレチック

草原・森・空の3ステージ。にんじん収集、動く足場、チェックポイント、一時停止、ローカルのクリア記録。
矢印キー/A・Dで移動、スペース/上矢印でジャンプ。モバイルは画面の左右とジャンプの同時押し。
外部ライブラリーや画像のダウンロードは不要。失敗しても回数制限なく再挑戦できます。
検証：8002番で静的サーバーを起動し、`python3 tests/bunny-platforms.py`（全3コースを実際の移動・ジャンプ操作でクリア）と `python3 tests/bunny-touch.py`（同時タッチ）を実行。Python Playwright と Chromium が必要です。

## モコモコ・カート

`kart/` はオリジナルの動物キャラクターによる疑似3Dカートレース。キャラクターを選び、3台のライバルと3周を競います。
自動アクセル、左右のハンドル、コイン、ダッシュパネル、3種類のアイテム（ダッシュ・前方の相手をスロー・バリア付きダッシュ）、順位、ベスト順位の保存。
矢印/A・Dでハンドル、スペースでアイテム。スマホでは画面のボタン。P/Escで一時停止。外部ライブラリー・外部画像は不要。任天堂のキャラクターや素材は使用していません。
ベスト記録は現在のブラウザー内のみ。オンライン対戦はありません。
検証は8002番で静的サーバーを起動し `python3 tests/kart-smoke.py`。実際のハンドルとアイテム操作で3周走行し、順位・全アイテム・一時停止・記録・タッチを確認します。

## おばけの館と、まほうのカギ

記録は現在のブラウザーのみで、再挑戦も含めた累積プレイ時間を保存。
検証は8002番で静的サーバーを起動し `python3 tests/ghost-smoke.py`。実際の移動で鍵を集めて脱出し、隠れる・追跡・再挑戦・保存・モバイル操作を確認します。

## ピッツァ・ポン！

`pizza/` は注文に合わせてトッピングし、焼いて提供する75秒のピザ屋さんゲーム。
4席のお客さん、7レシピ、具材の選択/取り外し、オーブン、正しい注文との照合、早い提供のボーナスとコンボ。
お客さんの待ち時間に応じて表情とゲージが変わり、待たせすぎるとブーブー音とともに帰ります。5人帰ると閉店。
「のんびり」「大いそがし」を選べます。来店間隔は営業後半に短くなります。
1〜4で具材、Bで焼く、Enterで提供、左右キーで注文変更。モバイルはすべてタップ操作。
音量の小さいWeb Audio効果音は開店操作後に有効になり、画面の音ボタンで消せます。一時停止中は焼き時間・来店・待ち時間も停止。
難易度ごとのベストは現在のブラウザーに保存。外部依存、実際の決済、オンライン機能はありません。
