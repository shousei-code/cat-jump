# 4人でカードパーティー
1人＋CPU3人のローカル対戦。オンライン対戦や途中セーブはありません。
- カラーカード：ウノ風の簡易ルール。自動ウノ宣言、+4なし、重ね出しなし、引いたらターン終了。
- ババ抜き：53枚、同じ数字のペアを自動除去。最後のジョーカー所持者が負け。
- レシピあつめ：オリジナルの材料交換ゲーム。料理ごとの6材料を集める。
静的ファイルだけで動作。画像・外部ライブラリ・通信不要。
テスト：`node cards/core.test.mjs`
ブラウザ：ルートで `python -m http.server 8010` を実行し `python tests/cards-smoke.py`。
