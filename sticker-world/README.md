# シールの島♡きらめきアスレチック

GitHub Pagesで一人で遊べる静的3Dゲーム。既存ゲームとは別の保存キー `sticker-island-v1` を使います。

## 遊び方

- 矢印／WASD／画面の方向ボタンで移動。スペース／ジャンプボタンでジャンプ。
- 3つのアスレチックと広場にシールが隠れています。旗がチェックポイント。落ちたら旗から再挑戦。
- 初めて見つけたシールは10コイン、各コースの初クリアは50コイン。同じ発見で報酬を重複取得できません。
- お届けのお仕事は30秒・最大10個。正しい箱1個につき8コイン。途中終了でも成功分を受け取れます。
- ガチャは4テーマ、各6種類、計24種類。1回30ゲーム内コイン、現金・課金・広告なし。重複は5コイン還元。各テーマで10回以内にレア以上を保証。
- 通常確率：ノーマル4種類それぞれ22%、レア10%、伝説2%。保証時はレア90%・伝説10%。確率を画面にも表示。
- 6キャラクター、4シール帳。シールを選んで12マスに配置。貼ったマスを押すと外せる。コレクションは減りません。
- コイン・発見・衣装選択・帳面を自動保存。別端末へのセーブ自動同期はありません。壊れた保存は上書きせず取り出せます。

## オンライン（試用版）

PeerJSの公開シグナリングサービスを使い、6桁の部屋コードで接続。ホスト1人＋ゲスト9人まで。WebRTCデータチャネルで座標とキャラクター番号だけを共有します。文字チャット・アカウント・音声・動画なし。サーバー側の永続保存なし。相手に表示する名前は用意済みキャラクター名です（位置表示に文字の名前ラベルは付けていません）。

通信はホスト経由で参加者に配信。ホスト退出時は一人用に戻ります。部屋が満員・コードがない・接続がタイムアウトした場合に案内を表示。シールやコインはそれぞれのローカル進行で、交換・対戦・ホスト引き継ぎはありません。公開PeerJS・STUNへの到達性とWebRTC利用可能な回線が必要です。TURN専用中継サーバーは用意していないため、学校等のネットワークや厳しいNATでは接続できない場合があります。外部サービスの稼働保証はありません。

**この開発環境ではChromium管理ポリシーがWebRTCの直接UDP通信を制限しています。** ローカルシグナリングでoffer/answerの交換まで確認しましたが、実データチャネルは開通せず、実端末10人で遊べたとは報告していません。通信制限は変更していません。10人上限・11人目拒否・位置配信・退出処理は模擬トランスポートの単体テストで確認。GitHub Actionsには通常のChromiumでの実WebRTCテストも設定しています。オンラインは試用表記です。

## 起動・検証

ビルド不要。リポジトリ直下で `python -m http.server 8000`、`http://localhost:8000/sticker-world/` を開きます。

```sh
node --test sticker-world/tests/*.test.mjs
python sticker-world/tests/browser.py
```

Python PlaywrightとChromiumが必要。ブラウザテストは1280pxと393pxタッチ設定で、移動・シール取得・お仕事・ガチャ・帳面の配置／削除・キャラクター・保存を確認。実機Safari/iPadは未確認。

WebRTCが許可された環境でのローカル通信検証：

```sh
npm ci --prefix sticker-world
node sticker-world/tests/signal.cjs
# 別ターミナル
python sticker-world/tests/network.py
```

通常プレイは公開PeerJS。localhostか127.0.0.1で `?localPeer=1` の場合だけポート9000のローカルシグナリングに接続。テスト用の任意の外部接続先指定機能はありません。

## 素材・ライブラリ

シール画像 `stickers.png` は画像生成ツールで新規制作した6列×4行の24点。人物・島はThree.jsで作ったオリジナルの立体モデルで、Robloxの素材やサービスを使用していません。Three.js 0.180.0、PeerJS 1.5.5の配布物とライセンスをvendorに同梱。ライブラリの読み込みにCDN接続は不要です。

主要ファイル：`core.mjs`（保存・報酬・ガチャ・ジャンプ計算）、`game.js`（3DとUI）、`network.js`（部屋通信）、`style.css`、`tests/`。

公開先：`https://shousei-code.github.io/cat-jump/sticker-world/`。公開用mainに反映するとGitHub Pagesが配信します。この開発環境から外部Pagesの応答は未確認です。

ブラウザ検証の移動部分は時計を制御して入力時間を固定します。その後は時計制御のない別のブラウザページで、お仕事・ガチャ・シール帳を実操作します。WebGLの描画負荷を減らすため、メニューを開いている間の背景更新は10fpsに抑えています。

開発時の確認：単体テスト6件成功（3コース到達、再挑戦、保存、ガチャ保証、お仕事、模擬通信での人数制限と退出）。PC・スマホサイズの一人用ブラウザ操作を確認。実WebRTCテストは前述の環境制限により未完了です。
