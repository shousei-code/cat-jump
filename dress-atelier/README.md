# リリィのドレスアトリエ
人物は自然な頭身を意識したSVGイラストです。写真や写実的な3Dモデルではありません。
髪型12、衣装20、靴10、アクセサリー10の選択肢。各カテゴリ24色。
設定の組み合わせは7,962,624,000通り。999万点の独立した衣装素材ではなく、一部は形状を共有したバリエーションです。
5つのお題、採点、再挑戦、自動保存、お気に入り6つ、呼び出し・削除、SVG画像保存。
呼吸・髪の微細なアニメーション。動きを減らす端末設定に対応。
音は初期オフ、外部通信なし。
検証: python tests/dress-atelier-smoke.py（ルートでポート8010のHTTPサーバーを起動）。
