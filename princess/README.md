# キラキラ学園♡運命のプリンセス

ことちゃんが魔法学園で友情とおしゃれを育む、全年齢向けの一人用ブラウザゲーム。**第1章から第12章、エンディングまで遊べます。** 既存のゲームは変更せず、このディレクトリに独立させています。

## 遊べる内容

- 全12章。歓迎祭、文化祭、冬休み、バレンタイン、時計塔の秘密、プリンセス決勝。
- 第9章でハルト・レン・アオイ・カイト・友情の進路を選択。5つの通常エンドと条件付き真エンド。ルート固有の会話と結末があり、章の大部分は共通です。
- 髪型・髪色・瞳・肌・服・靴・アクセサリーを透過イラストに反映。
- 102点のコレクション（基本30点＋髪とアクセサリーの色違い72点、初期所持17点）。102枚の別原画ではありません。
- ファッション対決、4レーンのリズム、記憶、謎解き、時間制限のお届けミッション。
- 第2章以降は練習と再挑戦が可能。ノーマル・ハード・エキスパート、エンド到達後のシークレット。
- 関係・性格・日記・実績・コイン・経験値。初回クリア報酬を集めることでレベル50と全ショップアイテム購入に到達可能。
- 自動保存、手動保存、JSON書き出し・読み込み。音楽・効果音は操作でオン。

第1章クリア画面の「物語の第2章へ」から続きを開始します。旧バージョンのセーブも利用できます。ミニゲームの途中で画面を離れた場合は、その挑戦の開始からやり直します。エンド後の再プレイでは衣装・記録・結末コレクションを保持します。

真エンドには、通常エンド、温室の謎解き、ハード以上のリズム・記憶・お届けクリア、ミオ・ユイ・セイラとの関係が必要です。「エンディング図鑑」に達成状況が表示されます。

## 起動・確認

Node.js 22以上を推奨します。

```sh
cd princess
npm ci
npm run dev
# http://localhost:5173
npm run check
npx playwright install chromium
npm run test:e2e
npm run preview
```

ブラウザテストは `npm run check` で生成した本番ビルドを使用します。先にビルドしてください。

既存のChromiumを使う場合：

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

PC・スマホともボタンのクリック／タップで操作できます。キーボードはTabで移動、Enterで決定。選択肢には関係と性格への効果を表示します。

## 第1章の対決ルール

得点 = メインタグ合計×3 + サブタグ合計×2 + 配色ボーナス。
同配色2点なら+3、3点なら+7、4点なら+12。同点はプレイヤーの勝ち。
髪色・瞳・肌は得点に影響しません。配色はアイテム固有の属性です。
ライバルは難易度に応じた固定の作戦から選択します。ランダム判定はありません。
すべてのテーマ・難易度を初期衣装だけで攻略可能です。
失敗時の消費はなく、テーマ×難易度ごとの報酬は初回のみ。再プレイでの報酬増殖も防止しています。

## 第2章以降のチャレンジ

合格点はノーマル55、ハード70、エキスパート85、シークレット95点。難易度に応じてリズム判定幅、記憶する数、お届けの制限時間が変わります。出題の順番は決まっており、練習で攻略できます。謎解きのヒントはエキスパート以上では表示しません。

リズムは光が判定線に重なるとき、対応する4つのボタンをタップします。キーボードの1〜4または矢印キーにも対応。記憶は光った順番を見てから入力、お届けは指定されたマークを選びます。ファッションはテーマに合わせて着せ替え、コーデ得点を100点満点に換算します。

練習の報酬は種目×難易度ごとの初回のみ、章の報酬も初回のみです。失敗でコインや衣装は失いません。

## 保存

バックエンド・ログイン・自動端末同期はありません。進行は同じ端末・同じブラウザ・同じサイトのlocalStorageに保存されます。プライベートブラウズやブラウザデータ削除で消える場合があるため、設定からファイルを書き出せます。別端末でそのファイルを読み込むと続きから遊べます。読み込み前に検証と置換確認を行います。壊れた保存データは自動上書きせず、元データを書き出せます。

広告・課金・チャット・個人情報収集・外部分析サービスはありません。

## 公開と更新

遊ぶURL： https://shousei-code.github.io/cat-jump/princess-play/

ユーザーの公開指示により、ビルドした静的ファイルをリポジトリ直下の `princess-play/` に配置。ゲームひろばにも入口を追加しています。既存のGitHub Pagesのmain / root配信設定で利用できます。`.nojekyll` で静的ファイルをそのまま配信します。

更新時はこのディレクトリで `npm ci && npm run check` を実行し、ブラウザテスト後に `dist/` の内容でルートの `princess-play/` を置き換え、変更をレビューしてmainへ反映してください。ソースの `princess/` は残します。

GitHub Actionsの手動公開ワークフローも `/princess-play/` に出力します。こちらを使う場合のみ、Settings → Pages → SourceをGitHub Actionsへ切り替え、mainから実行してください。CIはテストとビルド成果物を保存します。

バックエンドは不要です。相対パスでビルドされるため、HTTPサーバーのサブディレクトリでも配信できます。

## アートと音

学園背景はこのゲーム用に生成したオリジナル画像。主人公は旧SVGを廃止し、新しい透過イラストの顔・髪・衣装・装飾を合成します。男の子4人も同じ方向性で新しく制作したイラストに交換しました。参考作品のロゴやキャラクターは使用していません。

主人公は通常を含む11表情と瞬き、6髪型、10衣装、6靴、8装飾に対応。呼吸・髪と装飾の揺れ、会話と勝敗による表情変化、着替え時の傾きと光を実装しています。端末の「動きを減らす」設定では停止し、画面外では瞬きを止め、フレーム間隔が悪化すると演出を軽くします。衣装一覧は静止表示です。音楽はWeb Audioで合成するオリジナルの短いオルゴールです。

これは生成イラストによる2Dパーツアニメーションです。正式なLive2Dモデルや商用原画としての監修済み素材ではありません。男の子は各3表情とまばたき・呼吸・返答時のうなずき、女の子の友達は主人公の顔・髪素材を共用しています。素材仕様、制作プロンプト、技術比較、今後必要な素材は [docs/CHARACTER-ART.md](docs/CHARACTER-ART.md) を参照してください。生成元PNGは `art-source/`、配信用WebPは `public/art/characters/` に分離しています。
