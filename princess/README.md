# キラキラ学園♡運命のプリンセス

ことちゃんが自分のコーディネートで歓迎祭に挑む、全年齢向けの学園アドベンチャー。**第1章が最後まで遊べるMVP**です。既存のゲームは変更せず、このディレクトリに独立させています。

## 遊べる内容

- 第1章：6つの会話シーン、複数の選択、歓迎祭、章の結末。
- ことちゃんの髪型・髪色・瞳・肌・服・靴・アクセサリー。独自SVGのレイヤーに即反映。
- 30点の衣装（最初から17点）。ショップ購入、クリア報酬、秘密のドレス。
- 3難易度のファッション対決。クリア後は2つ目のテーマと再プレイを解放。
- 7人の友達・ライバル、選択で変わる関係・性格、日記、5実績。
- 中庭・図書室で手がかりを集める温室の謎解き。
- EXP・コイン・レベル（上限50）。MVPの報酬だけで50まで到達する設計ではありません。
- 自動保存、手動保存、JSON書き出し・読み込み。音楽・効果音は操作でオン。

10章以上・100点以上の衣装・個別恋愛ルート・複数エンディング・リズム/記憶ミニゲーム・シークレット難易度は**今後の拡張対象**で、今回実装した機能ではありません。設計は [docs/DESIGN.md](docs/DESIGN.md) にあります。

## 起動・確認

Node.js 22以上を推奨します。

```sh
cd princess
npm ci
npm run dev
# http://localhost:5173
npm run check
npx playwright install chromium
npm run test:e2e
npm run build
npm run preview
```

既存のChromiumを使う場合：

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

PC・スマホともボタンのクリック／タップで操作できます。キーボードはTabで移動、Enterで決定。選択肢には関係と性格への効果を表示します。

## 対決のルール

得点 = メインタグ合計×3 + サブタグ合計×2 + 配色ボーナス。
同配色2点なら+3、3点なら+7、4点なら+12。同点はプレイヤーの勝ち。
髪色・瞳・肌は得点に影響しません。配色はアイテム固有の属性です。
ライバルは難易度に応じた固定の作戦から選択します。ランダム判定はありません。
すべてのテーマ・難易度を初期衣装だけで攻略可能です。
失敗時の消費はなく、テーマ×難易度ごとの報酬は初回のみ。再プレイでの報酬増殖も防止しています。

## 保存

バックエンド・ログイン・自動端末同期はありません。進行は同じ端末・同じブラウザ・同じサイトのlocalStorageに保存されます。プライベートブラウズやブラウザデータ削除で消える場合があるため、設定からファイルを書き出せます。別端末でそのファイルを読み込むと続きから遊べます。読み込み前に検証と置換確認を行います。壊れた保存データは自動上書きせず、元データを書き出せます。

広告・課金・チャット・個人情報収集・外部分析サービスはありません。

## レビューとGitHub Pages

この変更は専用ブランチでレビューするためのものです。現在の公開サイトのトップ・既存ゲームを変更しません。

CIは単体テスト、ビルド、PC/スマホのブラウザテストを実行し、ビルド成果物とテストレポートを保存します。

公開は**レビューしてmainに取り込んだ後**、GitHubのSettings → Pages → SourceをGitHub Actionsに設定し、Actionsの「Publish reviewed Princess and existing games」をmainから手動実行します。公開ワークフローはmain以外で実行されません。既存ゲームを含むサイト全体を保持し、ビルド済みゲームを `/cat-jump/princess/` に追加します。ブランチへのpushだけでは公開しません。今回Pages設定変更・公開操作は行いません。

Viteのbaseは相対パス。distを任意のサブディレクトリに置いてHTTP配信できます。HTMLファイルの直接ダブルクリックではなくHTTPサーバーを使ってください。

## アートと音

学園背景はこのゲーム用に生成したオリジナル画像。男の子の立ち絵は当リポジトリの既存オリジナル素材を再利用。主人公・女の子の衣装は独自SVG。参考画像のロゴ・キャラクターは使用していません。音楽はWeb Audioで合成するオリジナルの短いオルゴールです。立ち絵はMVP用アートであり、表情・衣装表現は今後磨き込めます。
