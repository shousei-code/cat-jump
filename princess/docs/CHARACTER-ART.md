# キャラクター素材と描画方式の再設計

## 現状の原因と変更方針
旧SVGは顔・髪・衣装を幾何図形で組み立てていたため、塗りの情報量・線の強弱・身体比率が背景のイラストと揃わなかった。旧Avatarの図形描画を廃止し、新規生成した透過PNGアトラスをレイヤー合成する。既存の衣装ID・採点・セーブ形式は維持する。

## アートディレクション
ことちゃんは魔法とおしゃれが好きなプリンセス候補生。大きな紫の瞳、繊細なまつ毛、ピンクブラウンの長い髪、自然な頭身。全年齢向けの上品な制服、膝丈のスカート、フリル・金刺繍・アメジスト・真珠。参考作品のキャラクターやロゴは使用しない。新規生成のkeyartを以後の素材の画風・配色・顔の参照にする。

## 技術比較
- PixiJS：大量スプライト・メッシュ変形に適する。現在は少人数の立ち絵で、WebGLテクスチャ管理とアクセシビリティ対応が余分になるため今回は不採用。
- GSAP：タイムラインと複雑な演出制御に有効。現在の待機動作と短いイベントはCSS/ブラウザ標準APIで実装できるため依存を追加しない。
- Rive：専用のベクター/リグ素材が必要。今回のラスターイラストをそのまま変形する方法ではない。
- Live2D Cubism：正式な分割モデル・メッシュ・モーション・利用条件が必要。存在しないため採用しない。
- 採用：React + 透過WebPアトラス（原画PNGを別途保存） + CSS transform/opacity + 表情フレーム切り替え。これは**2Dパーツアニメーション**でありLive2Dモデルではない。視点変更や360度回転はできない。

## レジストレーション
論理キャンバス512×768。衣装ごとの首位置を(256,130)にそろえる。顔・髪は個別の位置補正をmanifestに記録する。背面髪→身体/衣装→顔→前髪→装飾の順。靴は衣装の足元を覆う独立レイヤー。素材アトラスの分離はCSSのクリップと画像のセル位置指定で行い、生成元PNGは改変しない。髪色・目・肌の変更は部分レイヤーの色調補正であり、色ごとに描き直した原画ではない。

## 制作プロンプトの共通仕様
“Original family-friendly premium Japanese anime RPG character, fine tapered colored line art, dimensional cel shading, soft reflected light, jewel-like violet irises with multiple highlights, delicate eyelashes, natural blush, glossy rose-brown hair with fine locks, luxurious modest princess academy outfit with dimensional lace, embroidered gold, satin bow and amethyst. Front view, consistent pose and scale, clean transparent alpha, no text/logos/background, no copying existing characters.”

- keyart：全身、1024×1536、頭から靴まで、余白付き、透過PNG。
- 表情：4列×3行、同一輪郭・サイズ・照明、髪/首/服なしの顔だけ。笑顔、大喜び、驚き、照れ、悲しい、怒る、困る、ウインク、目を閉じて笑う、ドキドキ、通常、瞬き。
- 髪：3列×2行、正面のウィッグだけ、顔の開口部は透過。ボブ、ツイン、ロング、三つ編み、ポニー、ウェーブ。
- 衣装：2列×2行、首から靴まで同じポーズの着衣ボディ。頭/髪なし。首と足の位置は個別メタデータで補正。
- 装飾：各セル独立、リボン・四つ葉・月・花冠・ベレー・イヤリング・レース・ティアラ。
- 男の子：2列×3行（列は人物、行は表情）、同一人物の通常・笑顔・困り顔、胸から上、同じ頭の高さと塗り。ハルト茶髪、レン黒髪、アオイ青髪、カイト銀髪。制服は同じ学園の意匠。

## 品質の限界と後工程
生成アトラスは手作業のパーツ分け原画ではない。髪の裏側・腕の裏・衣装の完全な背面はなく、動きの範囲を小さく制限する。素材不足や代用は実装後の一覧で明示する。商用原画/Live2Dの完成品として扱わない。目標60fpsは実機計測なしに達成済みとは記載しない。

## 実装素材一覧（今回新規生成）

|ファイル名（配信は .webp / 原画は .png）|内容|使用状況|
|---|---|---|
|koto-keyart|1024×1536の全身デザイン原案|画風の基準。ゲームは下記パーツを合成|
|koto-expressions|4×3の顔。通常＋10表情＋瞬き|会話・試着・勝敗|
|koto-hair|3×2の6髪型|既存6アイテムに対応|
|wardrobe-a / b / c|各2×2の着衣ボディ|既存10衣装。cの残り2点は未使用の衣装案|
|accessories|4×2の装飾|既存8アイテムに対応|

既存の靴6点は着衣ボディの足元を別レイヤーとして切り替える。別途描き下ろした6枚の靴原画ではない。髪色と瞳は色調補正、肌は顔の補正と肌色領域の色変換。肌変換は通常Worker内で行い、非対応環境ではCanvasで一度変換してキャッシュする。生成元を加工した完成原画と偽らないため、元PNGをそのまま `art-source/` に保存した。

## 実装した演出

- 自然な間隔の瞬き。口の表情は保ったまま目の部分だけ切り替える。
- 小さな呼吸と上下動、前後の髪と装飾の控えめな揺れ。
- タイトルの花びら・光粒・ロゴ出現、画面と会話人物の登場。
- 選択肢に応じた表情、対決の喜び/落ち込み、秘密の衣装獲得時の光。
- 着せ替え時の23度の傾きと光。背面原画がないため一回転ではない。
- 画面外の瞬き停止、非表示タブ/動きを減らす設定で停止、低フレーム頻度時の軽量モード。
- 必須レイヤーのデコードが終わるまで読み込み表示。小さな一覧画像は遅延読み込み。

## 不足している完成素材と次の制作依頼

今回の生成イラスト版は動作するが、以下は未制作。商用原画の監修や正式Live2Dリグまで完成したという意味ではない。

1. `koto/model3.json`・moc3・テクスチャ・物理/モーションデータ：正式Live2D用。SDK利用条件を確認し、専門制作が必要。
2. 衣装ごとの `skirt-front/back`、左右腕、袖、リボンの完全分離、髪の背面補完：現在は着衣ボディと一部装飾の合成。スカート単独の物理変形は未実装。
3. 4人の男の子の残り表情・全身パーツ：現在は各3種類の胸上イラストと閉じ目差分。
4. 女の子の親友/ライバル固有の顔と立ち絵：現在は主人公の素材を共用し髪や配色を変更。
5. 各アイテム専用の靴・全髪型の手描き色差分、髪と装飾の組み合わせごとの監修修正。
6. 衣装の布端や接合部、手指などを含む生成イラストの人手による最終原画チェック。

素材納品は透過sRGB PNG、共通512×768座標の2倍以上、首と足のアンカーを固定。顔・前後髪・身体・衣装・前後装飾を分離し、表情間で目鼻口の座標を一致させる。レイヤー名と座標をmanifestに明記する。

セーブ形式v1とアイテムIDは変更していない。新規プレイの初期髪型だけロングに変更し、既存セーブのボブや所持品を勝手に置き換えない。

## 継続改善：男の子のまばたきと会話リアクション

`haruto-ren-blink` / `aoi-kaito-blink` を新規生成。既存の2列×3行、1024×1536の人物アトラスを参照し、全6セルの両目だけを閉じる編集を依頼した。原画PNGを保存し、配信は透過WebPに変換。表示では目の周辺だけを柔らかい楕円マスクで重ね、髪・輪郭・衣装・口元は元の画像を保つ。

4人の3表情すべてでまばたきに対応。立ち絵の呼吸、返答で表情が変わったときの小さなうなずき、ことちゃんの表情変更時のリアクションを追加。キャラクターごとにまばたきの間隔を少しずらす。読み込み前・画面外・動きを減らす設定・小さなアルバム表示ではタイマーを動かさない。低負荷モードでは間隔を延ばす。

これは2Dイラストの目元の差し替えと小さな全体変形であり、正式Live2Dモデルや音声に同期した口パクではない。男の子の追加表情や分割した全身モデルは引き続き未制作。

閉じ目差分の生成指示：
> Edit the original 1024x1536, 2-column × 3-row portrait atlas. Preserve all six portraits' exact registration, face contours, hairstyles, lighting, uniform, mouths, and transparency. Only close both eyes in every portrait, with fine curved eyelashes and skin-colored eyelids. No iris visible. Preserve each row's existing mouth expression. No text, no resizing, no new pose. The runtime overlays only the eye region.

追加の配信素材は合計約1.1MiB。大きい立ち絵で必要になったときに読み込む。小さなアルバムの人物には閉じ目画像を配置しない。生成画像のセル境界が完全には均等でない箇所は、人物/行に応じて上端を3.5〜5.5%クリップして隣接セルの衣装を除去している。
