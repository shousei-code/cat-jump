# キラキラ学園♡運命のプリンセス — MVP設計書

## 今回完成させる範囲

第1章「招待状と、はじまりのランウェイ」を最後まで遊べるReact/TypeScript作品。タイトル、ことちゃんの見た目設定、分岐会話、着せ替え、得点内訳の見えるファッション対決、敗北後の着替え・再挑戦、章クリア、セーブ再開を一本の流れにする。専用ブランチでレビューし、既存の公開ゲームは変更しない。

## 体験とループ

タイトル → 外見設定 → 入学式で選択 → 友達との会話 → 学園マップ → テーマ確認 → 着替え → ライバルと対決 → 結果 → 再挑戦または章の結末。クリア後は練習対決、学園探索、衣装購入、章の再プレイを楽しめる。

## 世界と人物

主人公ことちゃん。明るいハルト、落ち着いたレン、優しいアオイ、自信家カイト。親友ミオ、衣装作りが好きなユイ、実力派ライバルのセイラ。健全な好意と尊重を描く。参照画像の固有キャラ・ロゴ・衣装は転載しない。リポジトリ用の生成イラストと独自レイヤーSVGを使用。

## ファッション

髪・服（ドレス/制服）・靴・アクセサリーの4スロット。髪色と瞳色は独立。cute/elegant/cool/natureのタグ点と配色で採点。乱数なし、テーマ・装備・難易度のみで決まる。ライバルは難易度ごとに候補からテーマに合う服を選ぶ。全難易度で初期コレクションから勝てる構成を自動検証。テーマ・スコア内訳・ライバルの服を対決前に表示。対戦に支払い不要、敗北で財産を減らさない。

## 保存と成長

version付き専用localStorage。経験値からLv.1〜50を算出。章/ミッション/探索の報酬は初回だけ。章の再プレイは関係値をリセット、コレクション・報酬履歴は維持。自動/手動保存、JSON書出し/読込み。破損セーブを自動上書きせず保護し、保存不可も表示。

## UIと音

日本語、44pxタッチ領域、キーボード、reduced motion。音は初期消音、操作後のみWeb Audioで開始。音量調整、非表示で停止。全機能を無音で遊べる。

## 次段階（MVPには含めない）

第2〜12章、4恋愛ルート＋友情＋真エンド、120点以上の衣装、リズム/記憶/時間制限ミッション、本格的な探索謎解き。Secretは全ストーリー完結後に追加。未完成ボタンは表示しない。MVPではNormal/Hard/Expertのファッション対決、第1章の結末を実装する。
