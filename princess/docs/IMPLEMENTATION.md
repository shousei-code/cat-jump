# 実装計画

> この文書は初期MVP時点の設計・記録です。全12章版の現在の機能は [README](../README.md)、追加実装は [COMPLETION-REPORT](COMPLETION-REPORT.md) を参照してください。

1. 既存リポジトリ確認と専用ブランチ（公開ゲーム保持）。
2. princess/ にReact・TypeScript・Vite・Tailwindを構築。
3. 状態・衣装・会話・採点・セーブ検証を純粋なゲームロジックとして実装。
4. 独自アバター、背景、人物、タイトル/物語/クローゼット/バトル/学園マップ/コレクション。
5. 保存復元、敗北再挑戦、章クリア、探索初回報酬、音、レスポンシブ対応。
6. 単体テスト：採点・攻略可能性・二重報酬防止・不正セーブ。
7. Playwright：物語完走、敗北と再挑戦、保存復元、スマホ。
8. CIテスト・ビルド・プレビュー成果物。Pagesはmain限定の手動操作とし、レビュー前に公開しない。

## MVP実装結果

上記1〜8を実装。既存のゲームとメニューには変更を加えていない。
タイトル・主人公の見た目設定・第1章・衣装30点・ショップ・3難易度の対決・温室の謎・関係と実績・音・保存を接続済み。
本格的なキャラクタールート、複数の結末、追加章と追加ミニゲームは次段階。

検証：
- 初期MVPのVitest 9件：第1章完走、全テーマ/難易度の初期衣装による攻略可能性、失敗再挑戦、二重報酬防止、買い物制約、謎解き、保存検証、レベル上限。
- TypeScriptの型検査とVite本番ビルド成功。
- Playwright：PC/タッチ端末で物語完走・再挑戦・保存再開・不正保存保護・ファイル読み込みを実行。
- ビルドを実際に /cat-jump/princess/ 配下で配信し、画像とJSのHTTPエラー、実行時エラーなし。PC/スマホで横方向のはみ出しなし。
- GitHub Actions上の実行結果、GitHub Pagesの公開環境そのものは未確認。公開ワークフローは実行していない。

キャラクター描画はその後、透過イラスト方式に全面移行。現行の構成・制約は CHARACTER-ART.md を参照。

ブラウザ自動テストは、開発サーバーの自動再読み込みの影響を避けるため、事前ビルドしたdistをVite previewで配信して実施する。CIではnpm run checkの後に実行する。
