# 全12章版の実装記録

## 完成したプレイループ

第1章の歓迎祭から第12章の結末まで、会話→着せ替え／チャレンジ→報酬→次章を接続。第2〜12章には33場面の選択会話があり、第9章の進路で固有会話と結末が変わる。失敗時は何度でも挑戦でき、クリア後は練習・結末集め・衣装収集を続けられる。

- 12章、4人のルート、友情、条件付き真エンド（計6結末）。文化祭・冬休み・バレンタイン。
- ファッション・リズム・記憶・謎解き・制限時間ミッション。4難易度、練習、初回報酬。
- 102アイテム（基本30＋髪と装飾の色違い72）。元のデザインを共有する色違いであることを画面・文書で明示。
- レベル上限50。有限の初回報酬でLv50と全ショップ購入に到達可能。12実績、関係・性格・日記。
- 旧v1セーブを保持した任意のcampaignフィールド追加。新規状態の検証、途中保存、JSON移動。再プレイで収集物・達成記録を保持。

## 主な変更ファイル

- `src/campaign/data.ts`：章、会話、ルート、結末。
- `src/campaign/engine.ts`：章進行、採点の受け取り、難易度、初回報酬、解放条件、保存検証。
- `src/campaign/Campaign.tsx`：会話、進路、練習、結末図鑑、進行一覧。
- `src/campaign/Challenge.tsx`：実時間入力を使う各ミニゲーム。タブ非表示では時計の進行を止める。
- `src/game/{types,data,engine}.ts`：旧状態との接続と色違いアイテム。
- `src/components/{Story,Closet,Avatar,Academy}.tsx`、`src/App.tsx`、`src/style.css`：第1章との接続、コーデ採点、色反映、実績、レスポンシブUI。
- `src/campaign/campaign.test.ts`、`tests/campaign.spec.ts`：全ルート・全章・結末条件・購入・報酬・保存・操作テスト。
- READMEと設計文書：実装範囲・操作・公開手順。

既存ゲームのファイルは変更していない。公開ワークフローは従来どおりmain限定・手動実行で、このブランチへのpushでは公開しない。

## ビジュアルと実現範囲

前段階で導入済みの透過イラスト、主人公11表情、男の子の表情・瞬き、呼吸・髪・装飾の揺れを維持。今回も会話への返答、成功・失敗に表情を接続している。生成済み画像以外の高品質原画を新たに制作したとはしていない。

正式なLive2Dモデルではなく2Dレイヤーアニメーション。少女の友人は主人公素材を共用。ルートの多くは共通章で、全章分の専用背景・イベントCG・声優音声はない。季節は会話とイベントで表現する。必要な追加原画と仕様は [CHARACTER-ART.md](CHARACTER-ART.md) に記録済み。

端末間自動同期、オンライン対戦、ログインはない。PC・タッチ端末サイズでブラウザ検証するが、実機iPhone/iPadの動作や60fpsは保証していない。
