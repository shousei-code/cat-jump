左右に進んで、足場へぴょん！ ガラス・木・雨・砂・泡の足場で音を集めよう。 点線の足場は着地すると消える！ 旗から何度でも再挑戦。

着地して音を楽しもう

🧊 ガラス　🪵 木　🌧 雨　🏖 砂　🫧 泡
点線の床：着地から0.85秒で消え、2秒後に戻ります。音なしでも遊べます。

パソコン：← → / A D で移動、スペース / ↑ でジャンプ。P / Esc で一時停止。
スマホ・iPad：下の左右ボタンとジャンプを一緒に押してね。音のかけらは全部取らなくてもクリアできます。
