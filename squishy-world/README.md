# ぷにぷにワールド♡スクイーズの家

ひとりで遊ぶ3D収集ゲーム。既存ゲームとは別の保存キー `squishy-world-v1` を使用。

- 6マップ：おかしの国の砂漠、どうぶつの森、真珠の海の洞窟、星空の超アスレチック、アイスクリーム雪山、虹の雲のてっぺん。
- 100種類の別デザイン。探索84種（初期所持1種を含む）、ゴール限定6種、残り10種はガチャ限定。ガチャは冒険限定以外の94種。
- 全100種類を収納できる5部屋×20棚。初取得時に自動配置。ずかんから選択して空き棚へ移動、棚の子を選んで片付け可能。
- 押すと変形して戻る2Dアニメーション、任意の合成効果音。各種類の初めてのお世話で5コイン。
- 4シリーズのガチャ：30コイン、通常レア率15%、10回以内のレア保証、重複で5コイン返却。
- 30秒のお届け仕事（最大80コイン）と順番記憶ゲーム（25コイン）。外部課金なし。
- 6アバター、壁紙4色、チェックポイント、再挑戦、自動保存。

## 操作
矢印/WASD移動、Spaceジャンプ。スマホは方向ボタンとジャンプ。難しいコースでは足場の端まで歩いて次の足場を狙う。メニューを開くと移動停止。

## 起動・検証
リポジトリルートで `python -m http.server 8000`、`http://localhost:8000/squishy-world/`。
ビルド不要。GitHub Pagesのmain/rootで公開可能。

```
node --test squishy-world/tests/core.test.mjs
python squishy-world/tests/browser.py
```
ブラウザテストはPython PlaywrightとChromiumが必要。

## 素材と実装上の範囲
`assets/` の4枚は画像生成で制作した各5×5のスクイーズ画像。各画像をCSSまたはThree.jsのUVで切り出す。スクイーズはイラストで、立体の柔体シミュレーションではない。3D世界はThree.js、アバターと背景は独自のプリミティブ造形。Three.js 0.180.0は既存の `../sticker-world/vendor/` と同フォルダのMITライセンスを利用。

オンライン対戦・他端末へのセーブ同期は未実装。この版は一人用。保存はブラウザ内のみ。破損した保存は上書きせず、一時プレイにする。
