# ミソラと放課後♡きらめきスクール — 素材仕様・画像制作プロンプト

## 共通指定

全年齢向けの日本のアニメ学園ゲーム。繊細な線画、透明感のある瞳、自然な体格、丁寧な布の陰影。ピンク、ラベンダー、ネイビーを基調に統一。高校生らしい健全な衣装とポーズ。文字・ロゴ・透かしなし。立ち絵は透過背景、同一キャラクターの顔立ちと髪色を維持。手足や装飾を隣の枠にはみ出させない。

ミソラ：参考画像のふんわりしたピンク髪、紫の瞳、かわいく親しみやすい男の子。カピバラが好き。すべての衣装で前髪の横に小さな紙のお札をつける。

## 1. 主人公の衣装追加

「女の子の着せ替え用、首から下の全身衣装を2列×2行に配置。頭・髪は描かない。全コマで同じ自然な正面の立ち姿、腕の位置、首と足元の基準位置を維持。左上：高い襟、膝丈、黒タイツの上品な黒白メイドカフェ服。右上：ピンクのカフェエプロンワンピース。左下：白とラベンダーの運動会ジャケットと紺のショートパンツ。右下：リボンとフリルの文化祭ステージドレス。透過背景、1024×1536。」

実素材：`assets/player/wardrobe-d.png`。既存Princessゲームの自作髪・表情・衣装素材をコピーして併用。衣装20点は14デザイン＋スカート色違い6点。靴20点は6つの靴デザインの色違いを含む。髪型6種、髪色5種、瞳色4種。登録位置と重なり順は `player-art.js` に定義。

## 2. ミソラの衣装9種

「共通指定のミソラを3列×3行の全身立ち絵にする。同じ顔・体格・頭身・画風を保つ。順に、夏の制服、えんじのカーディガン、白のスタジャン、学園王子の衣装、カフェのベスト、浴衣、レインコート、緑のセーター、ラベンダーのステージブレザー。各コマの上下左右に十分な透過余白。紙のお札をすべての髪につける。」

実素材：`assets/boys-extra-a.png`。実出力1254×1254、3×3。

## 3. ミソラの衣装5種と友だち・ライバル

「3列×3行の透過全身アトラス。最初の5人は同一人物ミソラで、ダッフルコート、学園のニットベスト、カピバラ料理人、ボーダーパーカー、白のコンサートスーツ。残る4人は別人。黒髪で落ち着いた男の子レン、銀髪で明るい男の子ソウタ、茶色のツインテールの女の子ミオ、ラベンダーの髪で自信のある女の子リナ。全員同じ画風、自然な学園制服、手足が切れない余白。」

実素材：`assets/boys-extra-b.png`。実出力1254×1254、3×3。元の6衣装と合わせミソラは異なるデザイン20着。友だちはハル・ユイ・レン・ソウタ・ミオの5人。リナは別枠のライバル。

## 4. ヘアピン20種類

「アニメゲーム用の繊細でかわいい髪飾りを5列×4行に整列。各セル中央に1点だけ、透過背景。順に、ピンクリボン、ラベンダーリボン、金の星、パール、桜、カピバラ、月、蝶、ハート、クローバー、いちご、デイジー、雪の結晶、音符、雲、ギンガムリボン、レースリボン、貝殻、ぶどう、王冠。隣のセルへのはみ出しや文字なし。1536×1024。」

実素材：`assets/player/hairpins.png`。20種類をセルごとに切り出して表示。生成結果の並びをゲーム内の名称に合わせて登録すること。

## 表示と制作上の制限

素材は画像生成ツールで制作した静止画。SVGは画像の切り出し・重ね合わせに使用。Live2Dモデルや骨格アニメーションではない。主人公は顔・髪・服・靴・ピンを合成し、会話に応じて用意済みの表情を表示する。元の6章の背景付きCGは衣装固定で、新しい着せ替えは自分づくり・恋の物語・学園イベントに反映される。
