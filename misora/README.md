# ミソラと放課後♡きらめきスクール

参考画像のピンク髪・紫の瞳のミソラをもとに作った、全年齢向けの一人用学園ゲーム。

- 全6章＋結末：校門、授業、ゲーム制作部、文化祭カフェ、実況ごっこ、冬の帰り道。
- 各章の会話選択で友情・勇気・ひらめきが変化し、3種類の結末に分岐。
- クイズ、順番記憶、制限時間の注文、タイミングの4種目。何度でも再挑戦可能。
- 思い出アルバム、結末収集、自動セーブ、JSON書き出し・読み込み。
- スマホのタッチ操作、キーボードでボタン移動・決定。端末の動きを減らす設定に対応。

`python -m http.server 8000` をリポジトリ直下で起動し、`http://localhost:8000/misora/` を開く。ビルド不要。

テスト：`node --test misora/tests/*.test.mjs`。ブラウザテストはPythonのplaywrightとChromiumを用意し `python misora/tests/browser.py`。

保存先はlocalStorageの `misora-school-v1`。既存ゲームのセーブは変更しない。別端末への自動同期なし。チャレンジ途中の入力・時計は保存せず、そのチャレンジの開始から再開する。破損した保存データは上書きせず設定から取り出せる。

## 素材

`assets/scenes.png` は添付された参考画像を参照して画像生成ツールで制作した6場面の3×2アトラス（1536×1024、1場面512×512）。SVGはこの画像を切り出す表示窓として使用し、キャラクターを図形で描画していない。顔を含むイラスト全体は静止画。各場面で衣装・表情は異なるが、個別の8表情差分とLive2Dは未実装。7つの依頼プロンプトすべてを独立した完成素材として用意したものではない。

参考画像の実在サービスのロゴは新規素材に使用しない。配信イベントは架空の演出で、マイク・カメラ・通信配信・チャット・課金・広告は実装しない。効果音はユーザーが有効にした場合のみWeb Audioで合成。

- Node単体テスト3件成功：全章・保存、全3結末への到達、重複解放防止、状態遷移・不正保存。
- ChromiumでPC幅1280px／タッチ画面幅393pxの全6章を実際に操作し、全4種目・結末・再読み込み・アルバム引き継ぎを確認。
- 記憶ミス、カフェ時間切れからの再挑戦、壊れたセーブを上書きしないことを確認。

- 公開URLは `https://shousei-code.github.io/cat-jump/misora/`。この開発環境は外部Pagesへの接続が制限されるため、本番応答は確認できない。


## 学園生活・着せ替えの追加

タイトルまたは物語画面の「学園生活・着せ替え」から、自由にイベントや買い物へ移動できます。元の6章をクリアする前でも遊べます。

- 洋服屋「カピ・クローゼット」：制服、カピバラパーカー、体操服、カフェエプロン、カーディガン、冬服。最初の2着は所持済み、初期120コイン。
- 新しい友だち：陸上部のハル、美術部のユイ。挨拶とイベントで仲良し度が上がる。初回の挨拶は20コイン。
- ゲーム制作部：ユイと4つのコマンドの順番を覚える。
- 運動会：ハルと3回バトンをつなぐタイミングゲーム。体操服なら成功ゾーンが広い。
- 文化祭カフェ：30秒以内に6人の注文を届ける。失敗時は無料で再挑戦。
- イベント初クリア80コイン、指定の服での初クリア20コイン。報酬の繰り返し取得は不可。全服を有限の初回報酬で集められる。

`assets/wardrobe.png` は6衣装のミソラとハル・ユイの全身イラスト8体の透過アトラス。全衣装でお札を維持。着せ替えは学園生活・イベント・洋服屋の立ち絵に反映される。元の物語6場面のCGは場面固有の衣装で固定。

保存形式v1に任意のschoolフィールドを追加し、旧セーブは物語の状態を保って初期衣装・コインを補完。物語を周回しても購入した服と学園の実績は保持する。新しいゲームで全データをリセットする操作は従来どおり確認付き。

追加ファイル：`school.mjs`（コイン・服・友だち・報酬・保存検証）、`school-ui.js`（学園・洋服屋・イベント）、`tests/school.test.mjs`、`tests/school-browser.py`。

追加後の検証：単体テスト計7件成功。PC・スマホのブラウザで、6着の購入と着用、友だちへの挨拶、3イベントの攻略、失敗再挑戦、服と報酬の保存復元を確認。既存6章の完走・再開・不正保存保護も再検証済み。衣装画像の隣の枠が映り込まないようにクリップを適用し、両画面幅で表示を確認。

## 自分づくり・ミソラとの恋（最新版）

タイトルの「自分をつくる・恋の物語」から開始できます。

- 名前、髪型6種、髪色5種、瞳色4種を選択。
- 主人公の服20点（14デザイン＋色違い6点）、ピン20種類、靴20点（6デザインの色違いを含む）。すべて無料の初期プレゼント。
- メイドカフェ・文化祭・運動会の衣装を実際の立ち絵に反映。
- ミソラの衣装は20デザインへ拡張。新しい14着は洋服屋で無料で受け取れます。
- 友だち5人（男の子3人・女の子2人）、別にライバルのリナ。
- 全8場面の新しい会話。文化祭と運動会は学校イベントのクリアで進行。最後は自分の選択で「恋人の約束」「大切な友だち」に分岐。
- 外見・名前・選択・結末を自動保存。旧セーブの章進行と所持品を維持して追加項目を補完。

追加コード：`player.mjs`（データ・進行・検証）、`player-art.js`（イラスト合成）、`player-ui.js`（着せ替え・会話）。素材仕様と再制作プロンプトは [IMAGE-PROMPTS.md](IMAGE-PROMPTS.md)。

検証コマンド：

```sh
node --test misora/tests/*.test.mjs
python misora/tests/browser.py
python misora/tests/school-browser.py
python misora/tests/player-browser.py
```

新しい会話のブラウザテストは、独立して検証する学校ミニゲームのクリア状態を保存データに設定し、解放条件とその後の結末を確認します。スマホ確認はChromiumの幅393px・タッチ設定での検証で、実機Safariの検証ではありません。

今回の確認結果：単体テスト11件成功。新しい自分づくり・恋の物語、学校イベントの各ブラウザテストをPC幅1280px／タッチ設定393pxで完走。服・ピン・靴の各20点、ミソラ20着、友だち5人、再読み込み後の外見・名前・結末保持を検証。実画像の読み込みと画面のはみ出しも確認。

### リンちゃんの追加

初めて遊ぶときの主人公を「リンちゃん」（短いパステルピンクのボブ・淡い紫の瞳）にしました。以前のセーブは外見も進行も維持します。着せ替え画面の「リンちゃんにする」で、服・ピン・靴や進行を残して名前と見た目を変更できます。専用の全身イラストと3表情の頭部素材を追加し、20着の服と合成表示します。専用ボブの髪・瞳の色は固定、他の髪型では変更できます。

追加検証：`python misora/tests/rin-browser.py`（PC・スマホサイズ、名前の会話反映、着替え、進行維持、保存復元）。
