# 月の魔女とユニコーンの約束
参考画像の魔女を題材にした、一人用の2D魔法アクション。全20ステージを順に解放し、最後に魔王を倒す。

- 星（無料・長押し連射）、電気（3体連鎖、騎士やボスに有効）、氷（減速）、回復。
- 第6ステージからユニコーン変身：6秒間の高速移動と被ダメージ半減。虹色のかけらを取得可能。
- 5・10・15・20面にボス。HPに応じて3段階の攻撃、赤い予告円を避けて戦う。
- 各ステージで全敵撃破と3つのかけら取得が目標。HPに応じて星1〜3個。
- ステージ紹介、失敗と再挑戦、魔王撃破後エンディング、クリア後の再プレイ。
- クリア記録・解放ステージは `moon-witch-v1` に自動保存。戦闘中の位置・HPは保存しない。端末間同期なし。
- 画像生成のキービジュアルと6キャラクターシートを使用。背景はCanvas描画、移動や魔法はコードによる演出。Live2Dやフレームアニメではない。
- 画像生成用20シーンのプロンプトは [IMAGE-PROMPTS.md](IMAGE-PROMPTS.md)。20枚の背景絵は未制作。

## 起動
リポジトリルートで `python -m http.server 8000`。`/moon-witch/` を開く。ビルド不要、外部ライブラリ不要。GitHub Pages main/root対応。

## 操作
矢印/WASD移動。J星、K電気、L氷、H回復、U変身。スマホは方向ボタンと魔法ボタン。近い敵を自動照準。メニュー表示と非表示タブで一時停止。

## 検証
`node --test moon-witch/tests/core.test.mjs`
`python moon-witch/tests/browser.py`（Python Playwright + Chromium）
